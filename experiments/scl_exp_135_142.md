# Experiment Set: scl_exp_135–142 (Phase 1)
## Principled Structural Losses for Lattice Emergence

### Background

exp_98 ("Kitchen Sink") was the best-performing SCL experiment (attr_spread=1.809, obj_spread=3.037, recon=0.056). Its rank ordering came from three proportionality losses (Pearson correlation-based) plus attr_sink. The exp_125-130 series established that IC MSE is critical for attr differentiation but also revealed the ortho paradox — the basis orthogonality design problem remains unsolved.

**Core problem with exp_98's approach:**
- `loss_attr_card_inv_prop` / `loss_obj_card_prop` / `loss_attr_obj_inv_prop`: These enforce rank ordering via **batch-level Pearson correlation** between cardinality and rank. This is a statistical proxy, not a structural constraint. It says "over this batch, higher cardinality should correlate with lower attr rank" — but doesn't constrain any individual concept.
- `attr_sink_loss`: Pushes combined concepts' attr ranks toward zero weighted by cardinality. Effective but blunt — doesn't use the actual lattice structure.

**This experiment set introduces principled replacements:**

### New Techniques

#### 1. Rank Complementarity (RC)
**Formula:** `rc = Tr(P_attr)/n_attr + Tr(P_obj)/n_obj`

**Targets:**
- Singletons: `rc = 1 + 1/n_obj = 1.25` (attr_rank=2, obj_rank=1)
- Non-singletons: `rc = 1.0` (by concept maximality)

**Why it works:** In the FCA lattice, as a concept's attribute subspace shrinks (fewer shared attributes), its object subspace must grow (more objects satisfy the weaker constraint). RC captures this tradeoff as a per-concept invariant. Cross pairs ({red_circle, blue_square}) share 0 attributes, so by concept maximality their extent is ALL objects → attr_rank=0, obj_rank=4, rc=0/2+4/4=1.0.

**What it replaces:** All three proportionality losses. Per-concept constraint vs batch-level correlation.

**Implementation:** `SubspaceConceptLattice.compute_rank_complementarity_loss()`

#### 2. Margin-Based Topological Sorting (MTS)
**Formula:** For each concept pair (i, j):
1. Compute asymmetric inclusion: `S_ij = ReLU(incl(i⊆j) - incl(j⊆i))`
2. If `S_ij > 0.1`: i is below j in the hierarchy
3. Enforce rank gap: `loss = ReLU(margin * S_ij - (rank_j - rank_i))`

**Why it works:** The lattice partial order is encoded in asymmetric inclusion. If concept A's subspace is properly contained in concept B's, then B is "above" A (more specific, higher rank). MTS reads this structure from the learned subspaces and enforces corresponding rank gaps.

**What it replaces:** attr_sink + proportionality losses. Structural per-pair constraint derived from actual subspace relationships.

**Config:** `margin_topological_sort_margin` (default 0.5) — required rank gap per unit of inclusion asymmetry.

**Bootstrapping concern:** At initialization, all subspaces are near-degenerate → inclusions are symmetric → no asymmetry → no MTS signal. The model needs an initial perturbation source (IC MSE, reconstruction noise, or RC) to create the first asymmetries that MTS can then amplify.

**Implementation:** `SubspaceConceptLattice.compute_margin_topological_sort_loss()`

#### 3. Bimodal Basis Orthogonality
**Formula:** Per pair: `min(|cos_sim|², (1-|cos_sim|)²)` — pushed toward 0 or 1 (nearest target wins).

**Balance:** Paired with entropy balance (`balance_weight * (max_ent - H(mean(|cos_sim|)))`) to ensure ~half aligned, ~half orthogonal.

**Why it's different from polarize:** Both push to {0,1}, but bimodal uses the quadratic of the closer target (steeper near targets, cusp at 0.5) while polarize uses x*(1-x) (symmetric parabola). At x=0.5: bimodal gradient is ambiguous (both branches equal), polarize gradient is 0 (maximum).

**Critical limitation:** Like polarize, bimodal has **zero gradient at the degenerate fixed point** (all |cos_sim|=1 → min(1,0)=0). The balance term provides the escape force. This is an inherent property of any per-pair penalty that has a minimum at |cos_sim|=1.

**What it replaces:** The rank-only basis_orthogonality mode. Adds per-pair factorization pressure.

**Implementation:** `"bimodal"` mode in `compute_basis_orthogonality_loss()`

#### 4. Higher Intersection Power Steps
**Config:** `intersection_power_steps: 12` (vs default 5)

Eigenvalue mapping: `λ^k` where k=power steps.
- k=5: λ=0.5 → 0.031, λ=0.9 → 0.59
- k=12: λ=0.5 → 0.00024, λ=0.9 → 0.28

Sharper intersection makes IC MSE more discriminating. Small eigenvalue differences become large after powering, amplifying the differentiation signal.

#### 5. Constrained Ambient Dimension
**Config:** `ambient_dim: 4` + `attr_obj_orthogonality_loss: 1.0`

With ambient_dim=4, attr (n_attr=2 slots × 2 dims) can span the full space. Adding attr-obj orthogonality forces attr and obj to compete for the limited 4 dimensions. This creates natural rank pressure without explicit rank losses.

### Phase 1 Experiment Design

All experiments start from exp_98 refreshed with `ic_mode=mse` (exp_135 baseline).

#### Isolation experiments (single technique change)

| Exp | Technique | What changes from baseline |
|-----|-----------|---------------------------|
| **135** | Baseline refresh | exp_98 + ic_mode=mse. Reference point. |
| **136** | RC only | Remove 3 proportionality losses. Add RC=10. Keep attr_sink. |
| **137** | MTS only | Remove 3 proportionality + attr_sink. Add MTS=10. |
| **138** | Bimodal | basis_ortho_type=[rank,bimodal,balance], balance_weight=10. Keep all else. |
| **139** | Power 12 | intersection_power_steps=12. Keep all else. |
| **140** | Dim 4 + ortho | ambient_dim=4, attr_obj_orthogonality=1.0. Keep all else. |

#### Combination experiments

| Exp | Techniques | What changes from baseline |
|-----|-----------|---------------------------|
| **141** | RC + MTS | Remove proportionality + attr_sink. Add RC=10, MTS=10. |
| **142** | All new | RC=10, MTS=10, bimodal+balance (bw=10), power=12. Remove proportionality + attr_sink. |

**Per-experiment hypotheses (falsifiable):**

1. **exp_135**: attr_card_2 < 1.5 (IC MSE enables differentiation that bounds couldn't)
2. **exp_136**: |attr_card_2 - 1.0| < |baseline_attr_card_2 - 1.0| (RC gives tighter rank targets)
3. **exp_137**: MTS loss becomes non-zero by epoch 20 (bootstrapping succeeds with IC MSE noise)
4. **exp_138**: Per-slot mean |cos_sim| < 0.8 (bimodal+balance breaks some degeneracy)
5. **exp_139**: attr_card_4 < attr_card_4_baseline (sharper intersection helps differentiation)
6. **exp_140**: recon_loss < 0.1 AND attr_card_2 < 1.5 (dim 4 doesn't kill recon AND helps structure)
7. **exp_141**: rank ordering strictly better than max(136, 137) on all cardinalities
8. **exp_142**: Best overall rank ordering among all Phase 1 experiments

### Phase 2 Planning

After Phase 1 results:
- If RC works: test RC + bimodal (factorization + coupling)
- If MTS bootstrapping fails: add RC as warm-up for MTS
- If bimodal+balance fails (same as polarize+balance): try ortho→bimodal anneal (from exp_134 approach)
- If power 12 helps: test power 15, 20
- If dim 4 helps: test dim 4 + RC + MTS (most constrained combo)
- If 142 shows conflicts: identify which technique pair conflicts and design targeted ablation

### Code Changes Summary

**`SubspaceConceptLattice.py`:**
- `compute_rank_complementarity_loss(P_attr_tensor, P_obj_tensor, singletons_mask)` — new method
- `compute_margin_topological_sort_loss(P_attr_tensor)` — new method
- `compute_basis_orthogonality_loss()` — added `"bimodal"` mode: `min(|cos|², (1-|cos|)²) × 10`
- `training_step()` — computes and sums RC + MTS losses, logs them

**New config params:**
- `margin_topological_sort_margin` (float, default 0.5): rank gap per unit asymmetric inclusion
- `balance_weight` (float, default 1.0): multiplier for balance/balance_sharp losses
- `rank_complementarity_loss` (loss weight): weight for RC loss
- `margin_topological_sort_loss` (loss weight): weight for MTS loss
