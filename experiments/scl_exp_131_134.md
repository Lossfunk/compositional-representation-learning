# Experiment Set: scl_exp_131–134
## Breaking the Degenerate Equilibrium Without the Ortho Paradox

### Motivation

Experiments 127, 129, 130 revealed a fundamental problem: replacing the "ortho" basis_orthogonality_loss with "polarize+balance" removes a critical destabilizing force needed for attribute differentiation.

**The Ortho Paradox** (from analysis of exp_127/129/130):
- "Ortho" is conceptually WRONG: it pushes ALL pairwise cos_sim toward 0, even for concepts that share attributes (e.g., blue circle and blue square should be aligned in the "color" slot).
- "Polarize+balance" is conceptually CORRECT: it allows both aligned (|cos_sim|=1) and orthogonal (|cos_sim|=0) pairs, with entropy balance preventing collapse to all-1.
- But ortho WORKS and polarize+balance DOESN'T.

**Root cause**: At the degenerate equilibrium (all cos_sim = 1.0):
- **Ortho**: ~3.4 gradient per slot, acting independently on each of 12 off-diagonal pairs
- **Polarize**: ZERO gradient (|1|×(1−|1|) = 0 — fixed point)
- **Balance**: ~0.69 gradient through a single scalar mean (6× weaker than ortho)

The IC MSE amplification loop requires a strong per-pair destabilizing force to start: reconstruction noise → slight differences → ortho amplifies → asymmetric intersections → IC MSE forces matching → backprop differentiates → factorization. Without ortho, this loop never initiates.

### Experiment Design

All experiments share exp_126 as the base (IC MSE, MLP encoder, ambient_dim=4, attr_force_orthogonal_basis=True) — the last working configuration.

| Exp | Strategy | basis_ortho_loss_type | Key Config Changes | Hypothesis |
|-----|----------|----------------------|-------------------|------------|
| 131 | Ortho + corrective losses | [rank, ortho] | +attr_sink=1, +cross_slot=1 | Ortho breaks degeneracy; attr_sink + cross_slot guide toward correct factorization |
| 132 | 50× balance weight | [rank, polarize, balance] | balance_weight=50, +attr_sink=1 | Raw gradient magnitude (50×0.69=34.5) compensates for lack of per-pair structure |
| 133 | Sharp quadratic penalty | [rank, polarize, balance_sharp] | balance_weight=50, +attr_sink=1 | (p−0.5)² has more uniform gradient than entropy; may break degeneracy more reliably |
| 134 | Hybrid ortho→polarize anneal | [rank, ortho, polarize, balance] | anneal [20,50], +attr_sink=1 | Ortho breaks degeneracy early; polarize refines toward correct target late |

### Detailed Experiment Descriptions

#### exp_131: Ortho + Corrective Losses
**Idea**: Don't fight ortho — embrace it as the destabilizer and add losses that correct its flawed direction.

- **basis_orthogonality_loss_type**: `[rank, ortho]` (same as exp_126)
- **attr_sink_loss**: 1.0 (provides independent differentiation pathway)
- **cross_slot_decorrelation_loss**: 1.0 (forces slots to encode independent factors)

This is exp_126 + attr_sink + cross_slot. Note that exp_130 tried polarize+balance+attr_sink+cross_slot and FAILED — but that was because cross_slot interfered with attr_sink's rescue of a system that lacked any destabilizing force. Here, ortho provides the destabilizing force, so cross_slot should act constructively to guide the already-differentiating representation toward slot independence.

**Expected outcome**: Should match or exceed exp_126's attr differentiation, potentially with better slot factorization (each slot cleanly encoding one attribute).

#### exp_132: 50× Balance Weight  
**Idea**: Brute-force the gradient magnitude gap.

- **basis_orthogonality_loss_type**: `[rank, polarize, balance]`
- **balance_weight**: 50.0 (effective gradient at degeneracy: 50 × 0.69 ≈ 34.5, ~10× ortho)
- **attr_sink_loss**: 1.0
- **obj_subspace_orthogonality_mode**: polarize

The balance entropy gradient at p=1.0 is `log(p/(1-p))` which diverges, but the clamped gradient at p=0.999999 is ~13.8. With weight=50, this gives ~690 effective gradient magnitude. Even through the scalar mean, this should provide massive pressure away from degeneracy.

**Risk**: May destabilize training entirely. The balance loss acts uniformly on all pairs through a single scalar — it has no per-pair structure, so even with overwhelming magnitude, it may push toward a different degenerate state rather than toward factorization.

#### exp_133: Sharp Quadratic Penalty
**Idea**: Replace entropy balance with (p−0.5)² — a sharper, more uniform penalty.

- **basis_orthogonality_loss_type**: `[rank, polarize, balance_sharp]`  
- **balance_weight**: 50.0
- **attr_sink_loss**: 1.0
- **obj_subspace_orthogonality_mode**: polarize

Gradient comparison at p=1.0 (full degeneracy):
- **Entropy balance**: `log(p/(1-p))` → diverges (clamped ~13.8), but loss value = 0.693
- **Sharp balance**: `2(p−0.5)` = 1.0, loss value = 0.25

The sharp penalty has weaker gradient at the boundary but more uniform gradient across [0,1]. With weight=50, the gradient at p=1.0 is 50×1.0=50, which is ~15× ortho. The key difference from entropy is behavior in the mid-range: sharp has constant d²/dp²=2 (uniform curvature), while entropy has d²/dp²=1/(p(1-p)) (high curvature at boundaries, low in middle).

**Expected outcome**: Smoother optimization than exp_132 due to more uniform gradient landscape.

#### exp_134: Hybrid Ortho → Polarize Anneal
**Idea**: Use ortho's strength (breaking degeneracy) early, then transition to polarize's correctness (allowing same-attr alignment) late.

- **basis_orthogonality_loss_type**: `[rank, ortho, polarize, balance]`
- **basis_ortho_anneal_epochs**: `[20, 50]`
  - Epochs 0–19: pure ortho (alpha=1.0)
  - Epochs 20–49: linear blend (ortho fades 1→0, polarize fades 0→1)
  - Epochs 50–99: pure polarize+balance
- **attr_sink_loss**: 1.0
- **obj_subspace_orthogonality_mode**: polarize

The anneal schedule is based on exp_126 analysis showing factorization begins by epoch ~15. By epoch 20, ortho should have broken degeneracy and established initial structure. The 30-epoch transition gives the model time to smoothly shift from "push everything apart" to "align same-attr, separate diff-attr". The final 50 epochs of pure polarize+balance should refine the representation toward the correct factorized target.

**Expected outcome**: Best of both worlds — ortho's escape velocity + polarize's correct target. Should show initial attr differentiation matching exp_126, then improved slot factorization as polarize takes over.

### Code Changes

**`SubspaceConceptLattice.py` — `compute_basis_orthogonality_loss`**:
1. **`balance_sharp`** loss type: `(p - 0.5)²` where `p = mean(|cos_sim|)`. Multiplied by `balance_weight`.
2. **`balance_weight`** config param (default 1.0): Multiplier for both `balance` and `balance_sharp` losses.
3. **`basis_ortho_anneal_epochs`** config param: `[start, end]` epoch range for linear interpolation. When active, `ortho` loss is scaled by `ortho_alpha` (1→0) and `polarize` loss is scaled by `polarize_alpha` (0→1). Rank and balance losses are unaffected by annealing.
