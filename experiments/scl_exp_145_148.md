# Experiment Set: scl_exp_145–148 (Phase 2)
## Cross-Slot Decorrelation and MTS Fix

### Motivation

The Phase 1 analysis (exp_143/144) revealed three critical failures:

1. **Both attr slots encode color** — same-color singletons have cos_sim ≈ 0.9999 in BOTH slots, same-shape singletons have cos_sim ≈ 0.02 in BOTH slots. Shape information is completely absent from attr subspaces.

2. **MTS is dead** — all singletons have rank ≈ 2.0 with symmetric inclusion between them (max asymmetry = 0.003). Zero pairs fire above the 0.1 threshold.

3. **IC pushes shape pairs to rank 0** — because both slots encode color, shape pairs have orthogonal singleton subspaces. The intersection target is rank ≈ 0, which is structurally wrong (should be 1).

### Root Cause

The ViT encodes color as a spatially uniform feature (every patch has same color) making it dominate mean-pooled representations (same-color patch cos_sim ≈ 0.99, different-color ≈ -0.96). When the bimodal basis_orthogonality demands {0, 1} patterns, both slots take the path of least resistance: color.

Nothing in the loss landscape enforces that **different slots encode different factors**. The bimodal loss is satisfied by any {0,1} pattern regardless of whether slots are redundant.

### New Technique: Cross-Slot Decorrelation

**Formula:** For each pair of attr slots (s, t), build the B×B absolute cosine similarity Gram matrices S_s and S_t from the singleton basis vectors, then:

```
L_decorr = (1/n_pairs) * Σ_pairs mean(|S_s[i,j]| · |S_t[i,j]|)  for i≠j
```

**Why it works:** If slot s has |cos_sim(i,j)| = 1 for a pair, the only way to minimize the product is to make slot t have |cos_sim(i,j)| ≈ 0 for that same pair. Combined with the bimodal loss requiring {0,1}, this forces complementary factorization patterns.

**Ideal behavior:** Slot 0 groups by color (same-color cos=1, different-color cos=0), Slot 1 groups by shape (same-shape cos=1, different-shape cos=0). The Frobenius product is then 0.0.

**Degenerate behavior:** Both slots group by color: product = 0.333 (high loss).

**Verified:** Smoke test shows factored pattern gives loss=0.0, color×2 gives loss=0.333 (33M× ratio).

### MTS Fix: Cross-Level Comparison

**Old:** MTS compared all concepts in P_attr_tensor. All singletons have rank ≈ 2.0 → symmetric inclusion → zero loss.

**New:** MTS explicitly computes intersection projectors `P_inter = (mean(P_singletons))^k` for each cardinality-2+ combination, then compares these against singletons. Since intersection rank < singleton rank by construction, the asymmetric inclusion creates real gradient signal.

### Measurable Hypotheses (Falsifiable)

1. **exp_145**: At least one slot has same-color cos < 0.5 AND same-shape cos > 0.5 (factorization achieved)
2. **exp_145**: Color pair attr_rank < 1.5 (down from 2.0 in exp_144)
3. **exp_146**: MTS loss > 0.01 by epoch 50 (no longer dead)
4. **exp_147**: Factorization achieved by epoch 20 (faster than exp_145)
5. **exp_148**: Recon < 0.10 AND at least one slot factorized (best of both worlds)

### Success Criteria

The target "checkerboard" factorization pattern:

| Pair | Slot 0 cos | Slot 1 cos | Description |
|------|-----------|-----------|-------------|
| circle_blue ↔ square_blue | 1.0 | 0.0 | Same color, different shape |
| circle_red ↔ square_red | 1.0 | 0.0 | Same color, different shape |
| circle_blue ↔ circle_red | 0.0 | 1.0 | Different color, same shape |
| square_blue ↔ square_red | 0.0 | 1.0 | Different color, same shape |

(Or the transpose: slot 0 → shape, slot 1 → color)

With this factorization:
- Color pair intersection: rank 1 (shared color slot aligned, shape slot different)
- Shape pair intersection: rank 1 (shared shape slot aligned, color slot different)  
- Cross pair intersection: rank 0 (both slots different)
- Singleton attr rank: 2.0 (both slots active)

### Code Changes

**`SubspaceConceptLattice.py`:**
- `compute_cross_slot_decorrelation_loss(X)` — Replaced cross-covariance formulation with Frobenius inner product of absolute cosine Gram matrices. Excludes diagonal. More direct penalty on same-slot-same-pair agreement.
- `compute_margin_topological_sort_loss(P_attr_tensor, P_attr_singletons, cardinalities_tensor, combination_indices)` — Added cross-level mode: analytically computes intersection projectors for each combination, then compares their rank to singleton rank via asymmetric inclusion and margin enforcement. Falls back to original all-pairs mode if singletons not provided.

### Phase 3 Planning

- If MTS fix helps: test with higher margin values
- If all works: scale to 3+ attr, 4+ obj datasets
